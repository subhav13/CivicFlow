# CivicFlow feature ledger

This directory is the durable source of truth for the CivicFlow WebMCP hackathon feature. Read `civicflow-webmcp-v1/MASTER.md` first, then `UPDATE_PROTOCOL.md`, `phases/00-index.md`, and the active phase document before changing the repository.

The ledger records the accepted synthetic-only product boundary, the one-state and one-capability-surface architecture, the human-only submission boundary, dependency-ordered packets, focused tests, and independent acceptance evidence. It does not authorize commits, pushes, Site creation or deployment, live APIs, secrets, or hosted configuration changes.

`sources/` mirrors and the attached planning documents are read-only references. New evidence belongs in the ledger according to `UPDATE_PROTOCOL.md`; do not silently rewrite an accepted decision or phase gate.
